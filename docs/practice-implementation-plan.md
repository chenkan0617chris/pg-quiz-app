# 练习与持久化实施计划

用户已授权开通 Neon 免费套餐并部署。使用已开通数据库，按当前题目版本保存原始题目及答案；公开响应使用 publicQuestion 投影。

- [ ] db/migrations/001_practice.sql：创建练习表及用户／时间索引，单次练习只计分一次；用户 ID 取自 Clerk 服务端会话。
- [ ] src/lib/practice-store.ts：发题保存、首次交卷原子更新、重复交卷返回原结果、查询本人最近 50 次已交卷练习、错题复练生成新记录。
- [ ] src/app/api/practice/route.ts：身份检查、请求大小及字段验证、数据库限流、统一错误响应；不在错误信息中输出数据库内容或密钥。
- [ ] src/app/practice/page.tsx：公开介绍、登录后选题、图形展示、数字输入、判分解释、下一题和错题复练；中英文支持。
- [ ] 测试：多解判分、非法答案、跨用户访问、并发交卷幂等；运行测试、lint、构建后重新部署，验证未登录接口和线上页面。

当前不启用会员付费限制。收款仍待真实商户、价格和 Stripe 服务条款；上线功能不显示虚假的可支付按钮。
